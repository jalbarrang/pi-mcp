# 0002: Use MCP SDK v1

## Context

The client needs protocol negotiation, stdio ownership, and a stable integration surface. SDK v2 is newer, and a hand-rolled client would duplicate protocol work.

## Decision

Use `@modelcontextprotocol/sdk` v1. Keep its dependency contained in the infrastructure connection adapter.

## Status

Accepted.

## Consequences

The established v1 API provides the current client surface. A future SDK migration is localized to infrastructure rather than the domain or application layers.
